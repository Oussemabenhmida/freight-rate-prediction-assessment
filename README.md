# Freight Rate Prediction Challenge

This project predicts `posted_rate` for the 12,000 loads in `data/validation.csv` using the 48,000 labeled loads in `data/train_test.csv`.

## Run

```bash
python -m pip install -r requirements.txt
python src/validate.py
python src/train_predict.py
python score.py --predictions validation_predictions.csv --december-predictions data/december_chart_inputs.csv
python src/make_report.py
```

## Validation

The task predicts two months after the last labeled date. Validation is therefore chronological:

- May-Jun through Aug-Sep are four rolling two-month windows used to select among pre-specified candidates by mean all-row MAE.
- Sep-Oct is a locked two-month final evaluation, not used in selection.
- Headline metrics include every holdout row. Target-based outlier flags are used only to make training robust; clean-label metrics remain diagnostic.

The selected model combines a linear model in log-rate space (distance spline, equipment, weight, market index, time trend, and quarter-end ramp) with a gradient-boosted residual model. It uses coordinates and geometry rather than city IDs, allowing it to score unseen validation cities.

## Outputs

- `validation_predictions.csv`: prediction template filled for all 12,000 load IDs.
- `data/december_chart_inputs.csv`: completed 31-day December input file.
- `scorer_results/candidate_december.png`: chart generated by `score.py`.
- `report/freight_rate_report.pdf`: validation method and chart.
- `results/validation_summary.json`: machine-readable selection and final evaluation metrics.

The final hidden-label score is calculated by the assessment provider after submission.
